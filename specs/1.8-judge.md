# 1.8 — Juiz (nota com look_for + verificação de citações)

## Contexto

O entrevistador (1.7) já chama um `Scorer` injetado para pontuar cada resposta; falta o juiz real. `judge.py` chama o prompt `judge` v1 (pergunta + `look_for` + resposta mascarada → `AnswerScore`) e o código confere o que o LLM devolveu: `criteria_met` dentro de `look_for` e `evidence_quotes` literais na resposta, preenchendo `quotes_verified`. Fontes: TRD §Módulos (`judge.py`), BACKEND_SCHEMA §Schemas (`AnswerScore`) e §Pipeline de validação (passos 4–5), PRD §Métricas (citações verificáveis).

## Requisitos

- R1. QUANDO `judge_answer` é chamado com uma pergunta e uma resposta, O SISTEMA DEVE chamar o prompt `judge` v1 via `prompts.run_prompt_structured` com `question` = `Question.text`, `look_for` = critérios unidos por `"; "` e `answer` = resposta, e devolver um `AnswerScore` validado.
- R2. QUANDO a resposta chega ao juiz, O SISTEMA DEVE mascará-la com `pii.py` antes da chamada (idempotente se já mascarada) e conferir as citações contra o mesmo texto mascarado que o LLM recebeu.
- R3. QUANDO `criteria_met` contém um item que não está em `question.look_for` (comparação exata após `strip`), O SISTEMA DEVE remover esse item.
- R4. QUANDO todas as `evidence_quotes` existem literalmente na resposta (`checks.quote_in_source`), O SISTEMA DEVE gravar `quotes_verified = True`.
- R5. QUANDO alguma `evidence_quote` não existe literalmente na resposta, O SISTEMA DEVE removê-la de `evidence_quotes` e gravar `quotes_verified = False` (ver P1).
- R6. QUANDO `evidence_quotes` vem vazia, O SISTEMA DEVE gravar `quotes_verified = True` (nada a conferir) e manter a nota do LLM (ver P2).
- R7. QUANDO o LLM devolve `quotes_verified` preenchido, O SISTEMA DEVE ignorar esse valor e usar só o calculado pelo código.
- R8. QUANDO o LLM falha no schema mesmo depois do reparo, O SISTEMA DEVE propagar `LLMInvalidOutputError` (o entrevistador já transforma em `score = None` via `score_answer`).
- R9. QUANDO `default_scorer(**llm_options)` é chamado, O SISTEMA DEVE devolver uma função com a assinatura `Scorer` da 1.7 que repassa `session_id`/modelo/`runs_dir`/`chat_model` para `judge_answer`.
- R10. QUANDO uma resposta fraca (genérica, sem exemplo) é julgada com o modelo real, O SISTEMA DEVE produzir nota ≤ 2 com justificativa não vazia (critério manual do plano; ver P3).
- R11. QUANDO a demo não consegue inicializar ou chamar o modelo por erro de configuração, O SISTEMA DEVE exibir uma mensagem curta em `stderr`, sem traceback, e encerrar com código 2.

## Fora de escopo

- Calibração contra nota humana, golden set e promptfoo (Fase 2, conjunto A).
- Novo prompt `judge` v2 (o TRD cita v2 como exemplo; esta tarefa usa a v1 existente).
- Ajustar a nota quando citações caem (o LLM redige a nota; ver P2).
- Agregação por competência, relatório e `candidate_summary` (1.9).
- Gravar a nota no DynamoDB / API (tarefas da Fase 3).

## Design

**Arquivos**

| Arquivo | Ação | Conteúdo |
| --- | --- | --- |
| `src/mia/judge.py` | criar | `verify_score`, `judge_answer`, `default_scorer` |
| `tests/test_judge.py` | criar | checagens puras + chamada com modelo falso |
| `scripts/judge_demo.py` (ou comando na CLI) | criar | roda o juiz real em 1 resposta fraca e 1 forte fictícias (só para o critério manual; ver P3) |

**Interfaces**

```python
# src/mia/judge.py
JUDGE_PROMPT: Final = ("judge", 1)

def verify_score(score: AnswerScore, question: Question, answer: str) -> AnswerScore:
    """Pure: filter criteria_met to look_for, drop unverified quotes, set quotes_verified."""

def judge_answer(
    question: Question,
    answer: str,
    *,
    session_id: str | None = None,
    **llm_options: Any,          # model, experiment, models, runs_dir, chat_model
) -> AnswerScore: ...

def default_scorer(**llm_options: Any) -> Scorer: ...   # Scorer de mia.interviewer
```

**Decisões**

- **Duas camadas:** `verify_score` é pura (testável sem LLM, reaproveitável pela avaliação da Fase 2); `judge_answer` = máscara → `run_prompt_structured` → `verify_score`.
- **Reuso:** `checks.unverified_quotes` para citações (mesma normalização da 1.5), `pii.mask` para a máscara, `Scorer` importado de `interviewer.py` (sem import circular: `judge.py` importa `interviewer`, nunca o contrário).
- **Resultado novo, não mutação:** `verify_score` devolve `score.model_copy(update=...)`.
- **Nada de SDK aqui:** só `mia.prompts`, `mia.checks`, `mia.pii`, `mia.schemas` (regra do `llm.py` único).
- Sem dependências novas.

## Plano de testes

`Question` fictícia com `look_for = ["cita exemplo concreto", "mede resultado", "explica trade-off"]`; resposta `"No projeto X reduzi a latência em 30% usando cache."`.

| Caso | Entrada | Esperado |
| --- | --- | --- |
| tudo certo | quotes `["reduzi a latência em 30%"]`, criteria `["mede resultado"]` | igual, `quotes_verified=True` |
| citação inventada | quotes `["reduzi a latência em 30%", "aumentei a receita"]` | só a 1ª fica, `quotes_verified=False` |
| paráfrase | quote `"diminuí a latência"` | removida, `False` |
| só espaço/aspas diferentes | quote com quebra de linha / aspas curvas | mantida, `True` |
| critério fora da lista | criteria `["mede resultado", "é simpático"]` | `["mede resultado"]` |
| critério com espaços | `[" mede resultado "]` | aceito como `"mede resultado"` |
| quotes vazias | `[]` | `True`, nota mantida |
| LLM manda `quotes_verified=False` com quotes válidas | — | `True` (código decide) |
| `judge_answer` feliz | modelo falso devolve JSON válido | `AnswerScore` verificado; variáveis do prompt com `look_for` unido por `"; "` |
| PII | resposta com e-mail | o texto enviado ao modelo falso está mascarado; citação do trecho mascarado verifica |
| reparo falha | modelo falso devolve lixo 2× | `LLMInvalidOutputError` |
| RunRecord | `judge_answer` com `runs_dir=tmp` | 1 linha com `prompt_name="judge"`, `prompt_version=1`, `session_id` |
| `default_scorer` | scorer usado em `interviewer.answer` com modelo falso | `answered.score` preenchido e verificado |
