# 0.4 — Esqueleto do repositório

## Contexto

Antes de qualquer código do cérebro (0.5 `llm.py` em diante), o repositório precisa de um projeto Python instalável com `uv`, lint com Ruff e testes com pytest, para que todo passo das próximas tarefas termine com `uv run pytest` e `uv run ruff check .` passando (`AGENTS.md`, "Comandos", "Convenções" e "Definição de pronto"; `docs/TRD.md`, "Estrutura do repositório e convenções").

Estado atual (commit `52362be`): já existem `.gitignore`, `.env.example`, `docs/` com os 7 documentos (PRD, TRD, APP_FLOW, BACKEND_SCHEMA, CASES, DESIGN, IMPLEMENTATION_PLAN), `AGENTS.md`, `.claude/` e `.agents/` com as skills, e o remoto `origin` (`github.com/nemofromdreamland/mia`) sincronizado com `main`. **Falta toda a parte Python:** `pyproject.toml`, `uv.lock`, `.python-version`, `src/mia/` e `tests/`.

## Requisitos

- R1. QUANDO o usuário roda `uv sync` num clone limpo, O SISTEMA DEVE criar `.venv/` com Python 3.12, instalar o pacote `mia` (layout `src/`) em modo editável e as dependências de desenvolvimento (pytest, pytest-cov, ruff), gerando ou respeitando o `uv.lock` versionado.
- R2. QUANDO o código roda `import mia`, O SISTEMA DEVE expor `mia.__version__` igual à versão declarada no `pyproject.toml` (`0.1.0`).
- R3. QUANDO o usuário roda `uv run pytest`, O SISTEMA DEVE coletar os testes de `tests/`, sair com código 0 e mostrar a cobertura de `src/mia/`.
- R4. QUANDO a cobertura de `src/mia/` ficar abaixo de 80%, O SISTEMA DEVE fazer `uv run pytest` falhar (`AGENTS.md`: "Cobertura mínima de 80%"). *(Depende da pergunta P2.)*
- R5. QUANDO o usuário roda `uv run ruff check .` e `uv run ruff format --check .`, O SISTEMA DEVE sair com código 0, usando a configuração do `pyproject.toml` (alvo Python 3.12).
- R6. QUANDO arquivos gerados localmente existem (`.venv/`, caches, `.coverage`, `htmlcov/`, `dist/`, `*.egg-info/`, `.env`), O SISTEMA DEVE mantê-los fora do git (`git check-ignore` confirma), enquanto `.env.example` e `uv.lock` continuam versionados.
- R7. QUANDO a tarefa termina, O SISTEMA DEVE ter `AGENTS.md`, os 7 documentos em `docs/` e nenhum `CLAUDE.md` na raiz.

## Fora de escopo

- Dependências de runtime (LangChain, LangGraph, Pydantic, boto3, FastAPI…): entram nas tarefas que as usam (0.5, 1.1, 3.x).
- Comando `mia` (entry point da CLI): tarefa 1.10.
- Pastas futuras (`cases/`, `prompts/`, `evals/`, `scripts/`, `runs/`, `config/`, `infra/`, `frontend/`, `docs/adr/`): cada uma nasce na tarefa que a usa.
- CI no GitHub Actions (`.github/workflows/`): Fase 4.
- README e licença: Fase 6.
- Checagem de tipos (mypy/pyright): nenhum documento pede; "tipagem em tudo" fica como convenção.
- Mudar o conteúdo de `AGENTS.md`, das skills ou dos documentos de `docs/`.
- `git push`: só com confirmação do usuário (ver P5).

## Design

**Arquivos**

| Arquivo | Ação | Conteúdo |
| --- | --- | --- |
| `pyproject.toml` | criar | `[project]` (nome `mia`, versão `0.1.0`, `requires-python = ">=3.12,<3.13"`, sem dependências de runtime); `[build-system]` hatchling; `[dependency-groups] dev` = pytest, pytest-cov, ruff; `[tool.pytest.ini_options]`; `[tool.coverage.*]`; `[tool.ruff]` |
| `.python-version` | criar | `3.12` |
| `uv.lock` | criar (gerado) | lockfile do `uv sync`, versionado |
| `src/mia/__init__.py` | criar | docstring do pacote + `__version__` lido dos metadados |
| `tests/test_package.py` | criar | teste de fumaça do pacote |
| `.gitignore` | alterar | acrescentar `.coverage`, `htmlcov/`, `dist/`, `build/`, `*.egg-info/` |

**Interfaces**

```python
# src/mia/__init__.py
"""MIA — Mock Interview Assistant."""

from importlib.metadata import version

__version__: str = version("mia")
```

**Configuração prevista (`pyproject.toml`)**

```toml
[tool.pytest.ini_options]
testpaths = ["tests"]
addopts = "--cov=mia --cov-report=term-missing --cov-fail-under=80"   # ver P2

[tool.coverage.run]
source = ["mia"]
branch = true

[tool.ruff]
target-version = "py312"
line-length = 100            # ver P3

[tool.ruff.lint]
select = ["E", "F", "I", "UP", "B"]   # ver P3

[tool.ruff.format]
exclude = ["*.md"]           # acrescentado no passo 4 (ver Notas)
```

**Decisões**

- **Layout `src/`** (`src/mia/`): é o que o TRD mostra e evita que os testes importem o código da pasta errada sem instalar o pacote.
- **Build backend hatchling**: é o padrão do `uv init --package` na versão de `uv` instalada (0.6.16); o `uv_build` exige `uv` mais novo.
- **Dependências de dev em `[dependency-groups]`** (padrão PEP 735, o que `uv add --dev` usa): não vão para quem instala o pacote, só para quem desenvolve.
- **`pytest-cov`** (dependência nova, justificativa): é a forma padrão de medir a cobertura mínima de 80% exigida no `AGENTS.md` dentro do próprio `uv run pytest`.
- **`__version__` via `importlib.metadata`**: uma única fonte da verdade (o `pyproject.toml`), sem número repetido no código.
- **Um teste de fumaça em vez de zero testes**: o pytest sai com código 5 ("nenhum teste coletado") quando não há testes, então "`uv run pytest` passa vazio" falharia. Ver P1.
- **Python 3.12 travado (`<3.13`)**: `AGENTS.md` fixa 3.12; a máquina tem 3.13/3.14 instalados, e a trava impede que o `uv` escolha um deles.

## Plano de testes

| Caso | Entrada | Esperado |
| --- | --- | --- |
| feliz: pacote importa | `import mia` | não levanta erro |
| feliz: versão | `mia.__version__` | `== "0.1.0"` (igual a `importlib.metadata.version("mia")`) |
| feliz: pytest | `uv run pytest` | `1 passed` (ou mais), código 0, tabela de cobertura com `src\mia\__init__.py 100%` |
| erro: pytest sem testes (contraprova da decisão) | `uv run pytest -k nenhum_teste` (nenhum teste selecionado) | `2 deselected`, código 5 (mostra por que precisamos do teste de fumaça) |
| erro: cobertura baixa (contraprova de R4) | arquivo temporário `src/mia/_tmp.py` com funções não testadas | `FAIL Required test coverage of 80% not reached`; arquivo apagado depois |
| feliz: ruff | `uv run ruff check .` / `uv run ruff format --check .` | `All checks passed!` / `N files already formatted` |
| erro: ruff pega problema (contraprova de R5) | `import os` não usado em arquivo temporário | `F401 ... imported but unused`; arquivo apagado depois |
| feliz: Python certo | `uv run python --version` | `Python 3.12.x` |
| feliz: ignorados | `git check-ignore .env .venv .coverage htmlcov` | lista os 4 |
| feliz: versionados | `git check-ignore .env.example uv.lock` | não lista nada (código 1) |
| feliz: docs | `ls docs/*.md \| wc -l` e `test ! -f CLAUDE.md` | `7` e código 0 |

## Notas de implementação

- Passo 1: `pyproject.toml` escrito à mão (sem `uv init`, para não gerar README/arquivos fora da spec); `pytest` entrou com `uv add --dev pytest` (resolveu `pytest>=9.2.0`). `[tool.hatch.build.targets.wheel] packages = ["src/mia"]` deixa explícito onde está o pacote. O `uv` avisa que a variável `VIRTUAL_ENV` do pyenv (3.13.1) não bate com `.venv`; é só aviso, o `uv` usa `.venv` com Python 3.12.12.
- Passo 2: teste escrito antes e visto falhando (`AttributeError: module 'mia' has no attribute '__version__'`). Contraprova trocada: `pytest tests/inexistente` sai com código 4 (caminho não existe = erro de uso), não 5; `pytest -k nenhum_teste` é que mostra o código 5 de "nenhum teste rodou".
- Passos 3–5 feitos de uma vez, a pedido do usuário ("os passos tão muito pequenos"), mantendo um commit por passo.
- Passo 3: `pytest-cov` e `ruff` entraram num único `uv add --dev pytest-cov ruff` (uma regeneração do `uv.lock` só), por isso o `ruff` já aparece no commit do passo 3; a configuração do Ruff fica no passo 4. Contraprova: `src/mia/_tmp.py` com 2 funções sem teste → `TOTAL 13%`, `FAIL Required test coverage of 80% not reached`, código 1; arquivo apagado. `source = ["mia"]` mede também arquivos que nenhum teste importa (por isso o `_tmp.py` apareceu com 0%).
- Passo 4: o Ruff 0.17.5 também formata blocos de código Python dentro de `.md` e queria reescrever trechos de `docs/BACKEND_SCHEMA.md` e `docs/TRD.md` (comentários alinhados à mão, linhas longas). Como mudar os docs está fora de escopo, `[tool.ruff.format] exclude = ["*.md"]`: a formatação vale só para `.py`. O `ruff check` já passava. Contraprova: `import os` não usado em `src/mia/_tmp.py` → `F401 ... imported but unused`, código 1; arquivo apagado.
