# 4.8 — CI: checks do PR

Aprovação: modo autônomo pedido pelo dono.

## Contexto

O plano pede no PR: Ruff, pytest, eval rápido e `terraform plan`; deploy via OIDC se der tempo (TRD, "CI/CD"). A 2.10 já criou `.github/workflows/ci.yml` (Ruff + pytest, sem segredos), e o eval rápido do conjunto A com respostas gravadas já existe como `tests/test_eval_regression.py` (replay do fixture `tests/fixtures/judge_cassette_set_a.jsonl`, sem modelo). Em 17/11 o dono decidiu não fazer upgrade: a conta AWS fecha hoje (PRD, "Restrições"), então qualquer passo que fale com a AWS falharia para sempre.

## Requisitos

- R1. O workflow DEVE ter, em jobs separados e visíveis no PR: `lint` (`ruff check .` e `ruff format --check .`), `tests` (`pytest`, sem segredos), `eval-quick` (só `tests/test_eval_regression.py`, nome "Eval rápido (conjunto A, respostas gravadas)") e `terraform` (`terraform fmt -check -recursive` e `terraform init -backend=false` + `terraform validate` em `infra/`).
- R2. Nenhum job DEVE usar segredo, credencial AWS ou chamar modelo; `permissions: contents: read` continua.
- R3. QUANDO um PR é aberto contra `main`, os 4 checks DEVEM aparecer verdes.

## Fora de escopo

- `terraform plan` e deploy via OIDC (desvio do plano: a conta AWS fecha hoje; registrar).
- Frontend no CI (lint/vitest/e2e): não pedido pelo plano.

## Design

**Arquivos**

| Arquivo | Ação | Conteúdo |
| --- | --- | --- |
| `.github/workflows/ci.yml` | alterar | 4 jobs (R1, R2) |
| `tests/test_ci_workflow.py` | criar | YAML parseia; jobs, comandos e ausência de `secrets.`/`aws-actions` |

**Decisões**

- Jobs separados (e não passos): cada um vira um check com nome próprio no PR.
- `hashicorp/setup-terraform@v3` com a versão do lock local (`~> 1.9`); `init -backend=false` baixa só o provider, sem state nem credencial.
- O eval rápido roda também dentro do `tests` (é um teste); o job próprio só o deixa visível.

## Plano de testes

| Caso | Entrada | Esperado |
| --- | --- | --- |
| jobs | `ci.yml` | `lint`, `tests`, `eval-quick`, `terraform` |
| comandos | `ci.yml` | `ruff format --check`, `test_eval_regression.py`, `terraform validate`, `-backend=false` |
| sem segredo (erro) | `ci.yml` | nenhum `secrets.`, `aws-actions`, `id-token: write` |
| real (verify) | PR no GitHub | 4 checks verdes |

## Critérios de aceite

- [ ] PR mostra os checks verdes — `gh pr checks <n>`
- [ ] `uv run pytest` e `uv run ruff check .` passam
