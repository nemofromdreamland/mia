# 4.9 — Vídeos de demo

## Contexto

O plano (`docs/IMPLEMENTATION_PLAN.md`, linha da 4.9) pede o vídeo de demo e o commit de `runs/` e `results/`. A demo pública sai do ar hoje junto com a conta AWS, então os vídeos são gravados por script (Playwright) contra produção, com legendas na página (sem áudio). Tokens de cor e fonte: `docs/design/02-tokens.md`.

## Requisitos

- R1. QUANDO o script roda com `--device desktop`, O SISTEMA DEVE gravar o fluxo completo (Início → caso Engenheiro(a) de Prompt Jr → preparação → entrevista até o fim → relatório → recrutador → resumo de um candidato → fechamento) em viewport 1280×720.
- R2. QUANDO roda com `--device mobile`, O SISTEMA DEVE gravar o mesmo roteiro com `devices["iPhone 13"]` (viewport 390×664, `isMobile`, toque).
- R3. Em cada etapa, O SISTEMA DEVE mostrar uma legenda numa faixa fixa embaixo, com cores e fonte dos tokens (`--surface-raised`, `--foreground`, `--mia`, IBM Plex Sans), reservando espaço para não cobrir botões.
- R4. As respostas da entrevista DEVEM ser pré-escritas, fictícias e preenchidas com `fill`.
- R5. Esperas longas (resposta do entrevistador, geração do relatório) DEVEM esperar o elemento aparecer, com legenda "Gerando relatório…", nunca pausa fixa longa.
- R6. Nenhum texto de legenda ou resposta DEVE conter URL, e-mail, número de conta AWS (12 dígitos), ARN ou UUID; um teste offline garante isso.
- R7. O vídeo final DEVE ter no máximo 2 min (alvo 60–90 s) e ficar em `media/`.

## Fora de escopo

- Áudio, edição manual. Mudanças no frontend ou backend.
- Instalar `ffmpeg` (ver Decisões).

## Design

| Arquivo | Ação | Conteúdo |
| --- | --- | --- |
| `media/scripts/demo_script.mjs` | criar | roteiro como dados: `CAPTIONS`, `ANSWERS`, `findSensitive(text)` |
| `media/scripts/demo_script.test.mjs` | criar | `node --test`: legendas/respostas sem dado sensível, tamanho das frases |
| `media/scripts/record_demo.mjs` | criar | grava com Playwright (carregado de `frontend/node_modules`) |
| `media/demo-desktop.*`, `media/demo-mobile.*` | criar | vídeos |

```js
export const CAPTIONS: Record<string, string>
export const ANSWERS: string[]
export function findSensitive(text: string): string[]   // padrões encontrados
```

**Decisões**

- Pergunta em aberto (formato sem `ffmpeg`): o `ffmpeg` não está no PATH e o download automático foi bloqueado pelas permissões. Opção recomendada e adotada: encurtar as esperas no script e entregar `.webm` (VP8, saída nativa do Playwright); a conversão para `.mp4` H.264 fica como passo manual depois de `winget install Gyan.FFmpeg`.
- Pedido do dono depois da gravação: tudo do vídeo (vídeos e scripts) fica em `media/`, que vai para o `.gitignore`; os vídeos e o script não são versionados. O script resolve o Playwright via `createRequire` apontando para `frontend/package.json`, sem dependência nova.
- Pedido do dono no meio da tarefa: a mascote MIA narra. A faixa traz o SVG do `MiaMark` (Design 4.3, 48 px), o rótulo "MIA ·" e falas em primeira pessoa; estado `speaking` ao falar e `thinking` nas esperas, nunca pela qualidade da resposta (Design 4.1).
- A legenda reserva espaço com `padding-bottom` no `body` e altura reduzida em `#root`.
