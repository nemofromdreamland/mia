# 3.6b — Tela Início (casos + histórico)

## Contexto

Bloco 1 da seção 14 do Design. O visitante escolhe um dos 5 casos, cria a sessão e vê o próprio histórico com a evolução da nota. Também cria o servidor de desenvolvimento do backend, que as telas 3.6b–3.6f usam para "navegar com o backend local". Fontes: Design 6.1, 5.5–5.7, 5.14, 5.21–5.26, 5.30, 5.31, 7.2, 9.2, 10.1, 13; Backend Schema "API" e schemas `CaseSummary`/`Session`.

Aprovação: modo autônomo pedido pelo dono em 16/11 (spec → implement → verify sem paradas); decisões abertas resolvidas pela opção recomendada e registradas abaixo.

## Requisitos

- R1. QUANDO o dev roda `uv run uvicorn mia.api.dev:app --port 8000`, O SISTEMA DEVE subir a API com repositórios em memória, `QuotaGate` em memória (demo aberta) e as dependências reais de modelo (mesma fiação de `simulation.default_deps`).
- R2. QUANDO o Início abre, O SISTEMA DEVE chamar `list_cases` e `list_sessions` e mostrar o H1 "Treine uma entrevista de emprego com a MIA", o texto de apoio e o rótulo "ESCOLHA UM CASO" com os 5 `CaseCard` na ordem da API (3/2/1 colunas).
- R3. QUANDO os casos estão carregando, O SISTEMA DEVE mostrar 5 skeletons de 180 px; QUANDO `list_cases` falha, InlineNotice `danger` "Não foi possível carregar os casos." com "Tentar de novo".
- R4. QUANDO o visitante clica num `CaseCard` (ou abre `/?caso=<case_id>`), O SISTEMA DEVE abrir o `CaseDialog` com título, subtítulo, "A VAGA", "VOCÊ VAI INTERPRETAR", aviso de anonimato e os botões "Cancelar" e "Começar" (`data-testid="start-case"`).
- R5. QUANDO "Começar" é clicado, O SISTEMA DEVE chamar `create_session {case_id, mode: "text"}`, mostrar "Criando…" e navegar para `routeForStatus` da sessão criada (Preparo).
- R6. QUANDO `create_session` devolve `quota_exceeded` ou `demo_paused`, O SISTEMA DEVE mostrar no diálogo o InlineNotice `warning` da seção 5.31 e desabilitar "Começar"; QUANDO devolve `demo_paused`, também mostrar acima dos casos o InlineNotice `warning` da seção 6.1.
- R7. QUANDO o visitante tem sessões, O SISTEMA DEVE mostrar o H2 "Suas simulações neste navegador", a tabela (desktop) ou cards (celular) de `SessionRow` com as colunas e ações por status da seção 5.7 (coluna "Caso"), `StatusBadge` e `RubricScore` `sm`; sem sessões, a seção não aparece.
- R8. QUANDO há exatamente 1 sessão `completed`, O SISTEMA DEVE mostrar o card "A evolução aparece a partir da segunda simulação concluída."; com 2 ou mais, o `EvolutionChart` da seção 9.2 com resumo `sr-only`.
- R9. QUANDO o visitante confirma "Apagar" numa linha, O SISTEMA DEVE chamar `delete_session`, mostrar `Loader2` na linha, remover a linha e mostrar o toast "Simulação apagada."
- R10. QUANDO o visitante confirma "Apagar meu histórico", O SISTEMA DEVE apagar cada sessão, limpar as chaves `mia:*`, gerar um `visitor_id` novo e esconder a seção de histórico.
- R11. QUANDO o `localStorage` não está disponível, O SISTEMA DEVE mostrar o InlineNotice `neutral` "Seu histórico não será guardado neste navegador."
- R12. QUANDO um erro não tratado acima acontece, O SISTEMA DEVE usar `errorMessage(..., "home")` e o toast da seção 5.22.

## Fora de escopo

- Formato "Voz" no diálogo (`VITE_VOICE_ENABLED` fica desligado; voz é tarefa à parte).
- Persistência real (DynamoDB) no servidor de dev; demora > 10 s do skeleton e demais linhas da seção 10.2 (3.7).
- As outras telas (3.6c–3.6f).

**Decisões**

- Servidor de dev em `src/mia/api/dev.py` (desvio aprovado na 3.6a: não havia comando para subir a API). Ele monta `ServiceDeps` com `InMemory*`, `QuotaGate(InMemoryMetaStore())`, `should_follow_up`, `default_writer`, `default_scorer` e `run_report` (sem SDK fora de `llm.py`).
- Coluna "Caso" mostra o `title` do caso (via `case_id`); se o caso não existir mais, `job_title`; se nulo, "Vaga sem título".
- Ordem das sessões: `created_at` decrescente. Gráfico: `completed` em ordem crescente, no máximo 20.
- Recharts recebe as cores hex da seção 9.2 (exceção prevista no "Pronto quando" do Design).
- O diálogo bloqueado guarda o erro por sessão de página: depois de `quota_exceeded`/`demo_paused`, todo diálogo aberto já vem com "Começar" desabilitado.
- Fetch na montagem com `useEffect`; sem biblioteca de cache (não há dependência nova).
