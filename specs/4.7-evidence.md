Data: 2026-11-17. URL: https://<distribution>.cloudfront.net · API: https://<api-id>.execute-api.us-east-1.amazonaws.com

Tarefa do dono ("Você"). O dono fez as entrevistas pelo site (Edge e Chrome) e pediu para confirmar a tarefa ("pode confirmar a 4.7"). O agente conferiu os dados de produção e completou o que faltava: a 3ª entrevista completa do mesmo caso, feita pela API, e o teste do kill switch.

## O teste revelou e corrigiu

| Problema | Correção |
| --- | --- |
| Criar sessão dava "Erro interno": o AgentCore rejeita status ≠ 200 do container | 4.7a (`/invocations` sempre 200) |
| Chrome continuou no código antigo depois do deploy: microVM por `runtimeSessionId` | encerrar as sessões do runtime após cada deploy (registrado na 4.7a) |
| Custo preso na microVM efêmera | 4.7b (`MIA_RUN_RECORD` no CloudWatch → `scripts/pull_runs.py`) |
| Fala do entrevistador cortada (400 tokens); entrevista longa | 4.7c (prompt v2, `finish_at_sentence`, 3 perguntas, ~6 min) |
